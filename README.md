# Lab 4

## Overview

A game where the player moves left and right to avoid falling blocks

## Run

Open `GameLoopKeyPress.html` in a modern browser. The game loads Three.js from the unpkg CDN, so an internet connection is required.

## Controls

- Move with `S`, and `D`.
- Arrow keys also move the cube.

## Gameplay
- Avoid the falling cubes
- If a falling cube hits you, you lose
- Score points every second
- Difficulty increases the longer you stay alive
- Try to get the highest score
